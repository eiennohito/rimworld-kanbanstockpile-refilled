# KanbanStockpile-Refilled

Limit the number of stacks of each item in a stockpile or shelf. When the limit
is one stack per item, you can also choose a smaller stack size. Set a refill
threshold so pawns leave partly used stacks alone until supplies run low.

For a 60-steel stack at 50%, refilling starts at 30 steel or fewer. Pawns then
continue refilling above that threshold, skipping small final top-ups. Deliveries
already on their way count toward the limit.

With Pick Up And Haul Reworked, pawns can bring several stacks in one trip.
Construction deliveries are unchanged. Multiplayer is not supported.

With Pick Up and Haul - Continued by Zzyxzz, storage with limits uses ordinary
hauling. Storage set to Off keeps Continued's inventory batching.

Refilled continues [KanbanStockpile Continued by Endag](https://steamcommunity.com/sharedfiles/filedetails/?id=3767756434),
based on the [original KanbanStockpile by ubergarm](https://steamcommunity.com/sharedfiles/filedetails/?id=2287142613).
It supports RimWorld 1.7 and requires Harmony. Enable it in place of those versions.
